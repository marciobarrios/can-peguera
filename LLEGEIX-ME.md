# Can Peguera, memòria viva

Web editorial estàtica en català i castellà. El repositori és públic i els desplegaments públics estan autoritzats segons `AGENTS.md`. [Documentació tècnica completa en castellà](README.md).

Inclou sis etapes històriques, 31 fites documentades, deu fitxes de llocs, mapa del barri 47 amb quatre punts orientatius, comparador de sis cobertures aèries de l’ICGC, 53 fotografies i plànols seleccionats, memòria comunitària i fonts. Els controls, avisos, peus, textos alternatius i metadades tenen versió ca/es.

```sh
npm ci
npm run build
npm run preview -- --port 4173
```

Entrades `/ca/` i `/es/`. No necessita servidor de dades, credencials ni analítica. La recerca íntegra és a `research/`, ignorada per Git. Els originals no s’han modificat.

Setze peces tenen l’autorització de reproducció pendent. Es mantenen els avisos individuals ca/es, l’autor o dipositari i la font. L’autorització de desplegament i els avisos no acrediten el permís dels titulars ni canvien l’estat pendent d’aquestes peces. No s’aplica cap llicència global a les imatges. Consulteu `docs/DERECHOS.md`.
