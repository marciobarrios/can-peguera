# Can Peguera web

Web estática bilingüe ca/es. Investigación local íntegra en research/, siempre excluida de Git. No subir corpus, ZIP, originales masivos ni textos íntegros de terceros. En Git solo código, contenido editorial seleccionado, datos y derivados utilizados, atribuciones y documentación técnica.

El repositorio marciobarrios/can-peguera es público. El usuario autoriza commit, push y despliegues públicos de la web, sin restricciones de despliegue ni requisito de preview privada.

Mantener en las imágenes pendientes de permiso el aviso individual ca/es, autor/depositario y fuente. La autorización de despliegue y el aviso no equivalen a una licencia del titular ni a una licencia global para las imágenes. No inventar hechos o testimonios; futuro como programación o propuesta. Mantener accesibilidad y equivalencia de idiomas.

El hook de pre-push se mantiene activo durante la implementación. No eludir controles de subida del corpus.
