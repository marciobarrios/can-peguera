# Can Peguera web

Web estática bilingüe ca/es. Investigación local íntegra en research/, siempre excluida de Git. No subir corpus, ZIP, originales masivos ni textos íntegros de terceros. En Git solo código, contenido editorial seleccionado, datos y derivados utilizados, atribuciones y documentación técnica.

El usuario autoriza commit y push de la web al repositorio privado marciobarrios/can-peguera. No desplegar públicamente. Imágenes pendientes de permiso solo en preview privada con aviso individual ca/es, autor/depositario y fuente. El aviso no equivale a autorización de publicación. Revisar derechos antes de lanzamiento público, sin licencia global para imágenes. No inventar hechos o testimonios; futuro como programación o propuesta. Mantener accesibilidad y equivalencia de idiomas.

El hook de pre-push se mantiene activo durante la implementación. No eludir controles de subida del corpus.
